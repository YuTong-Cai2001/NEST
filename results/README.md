# Result files

- `zero_shot_runs.csv` is appended by `train_anomaly_gfm.py`.
- `few_shot_runs.csv` is appended by `few_shot_finetune.py`.
- `paper_reported_baselines.csv` contains values transcribed from the current manuscript. They are explicitly marked unverified and are not generated by this repository.
- `figures/generated/` is created by `plot_results.py` and contains both PNG and PDF figures plus aggregated CSV tables.

Do not replace repaired-run results with the manuscript-reported SPAD row. The plotting script automatically prefers repaired full-model runs when they exist.
