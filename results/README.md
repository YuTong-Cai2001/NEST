# NEST result files

- `zero_shot_runs.csv` is appended by `train_anomaly_gfm.py`.
- `few_shot_runs.csv` is appended by `few_shot_finetune.py`.
- `paper_reported_baselines.csv` contains values transcribed from the current manuscript. They are explicitly marked unverified and are not generated by this repository.
- `figures/generated/` is created by `plot_results.py` and contains both PNG and PDF figures plus aggregated CSV tables.

The current manuscript's fixed-query few-shot measurements are in `few_shot_curve_runs.csv`, with aggregates in `few_shot_curve_mean_std.csv`. Within each seed, all shot counts use the same query set after excluding the maximum support pool; its zero-shot reference is recomputed on that query set. The residual-adapter trial files describe an alternative experiment, not the current paper's few-shot procedure.

Historical result keys and filenames retain their original identifiers for reproducibility. They refer to NEST where they identify the full method. Do not overwrite reproduced measurements with values transcribed from an earlier manuscript. The plotting script prefers reproduced full-model runs when they exist.
