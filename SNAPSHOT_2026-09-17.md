# SPAD reproducibility snapshot (2026-09-17)

This snapshot preserves the best verified seed-42 SPAD run before baseline
repositories are introduced.

## Result

- Run: `spad_dipt_full_seed42`
- Source: DGraphFin
- Target sequence: FiGraph 2018--2022
- Evaluated snapshot: FiGraph 2022
- Evaluation population: target nodes with labels exactly 0 or 1
- ROC-AUC: `0.7881910122754652`
- Average Precision: `0.1083799521916077`
- Seed: `42`
- Training epochs: `50`
- Prototype mode: `single`

FiGraph `Label=-1` nodes are unlabeled background entities and are excluded.
Numbers obtained by treating those nodes as normal are not comparable with this
snapshot.

## Reproduction command

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_experiments.ps1 -Seeds 42 -Epochs 50 -Variants full -SkipFewShot
```

## Development evidence

The 2019--2021 prefix-validation mean for the retained recency-aware local
score was AUC `0.74750340` and AP `0.15603070`. Tested alternatives including
two-hop diffusion, attribute/representation dual-view fusion, covariance-
scaled residuals, self-loop removal, and raw structural statistics did not
provide a reliable improvement and are not part of the preserved main path.
